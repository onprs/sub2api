# 套餐、计费与额度

## 余额计费与订阅套餐

| 类型 | 权益来源 | 请求如何计费 | 主要页面 |
| --- | --- | --- | --- |
| 余额计费 | 充值、余额兑换码或运营赠送 | 按模型费用和倍率从余额扣除 | [用量记录](https://cdn.api.onprs.top/usage) |
| 订阅套餐 | 购买套餐、套餐兑换码或运营分配 | 使用订阅有效期和额度窗口 | [我的订阅](https://cdn.api.onprs.top/subscriptions) |

同一账号可以同时拥有余额和一个或多个订阅，但具体请求使用哪一种由 API Key 的分组决定：

- 标准计费分组检查余额。
- 订阅分组检查该分组的有效订阅和额度。
- 订阅分组没有有效权益时，通常返回 `403`，不会自动退回余额计费。

因此，创建 Key 时必须选对分组。

## 套餐页面中的字段

当前可售内容以[购买套餐](https://cdn.api.onprs.top/purchase)为准。常见字段包括：

- 套餐价格与划线原价。
- 续费折扣及当前是否符合续费条件。
- 有效期和对应分组。
- 库存和是否仍在售。
- 支持的模型范围。
- `5h / 7d / 30d` 美元额度。

价格、库存、促销和模型范围会变化，文档不构成静态报价或长期可售承诺。

## 美元额度与实际付款

额度中的 USD 是统一的模型用量计价单位，不等同于你每次订单实际支付的币种或金额。请求成本通常由 Token、缓存、图片或按次价格计算，再应用分组、账号或时段倍率。

例如，套餐标注的 `$10` 用量额度表示最多累计 `$10` 的计价用量，不代表订单必然支付 `$10`，也不代表可退款现金余额。

最终以[模型价格](https://cdn.api.onprs.top/model-pricing)、订单和用量记录为准。

## 多个权益同时存在

同一分组的不同套餐可以形成独立订阅。服务会选择当前仍有效且未耗尽的可用订阅；较早的套餐耗尽时，后续可用套餐仍可能接管请求。相同套餐再次购买通常续期同一条套餐权益。
