# 套餐、计费与额度

## 余额计费与订阅套餐

| 类型 | 权益来源 | 请求如何计费 | 主要页面 |
| --- | --- | --- | --- |
| 余额计费 | 充值、余额兑换码或运营赠送 | 按模型费用和倍率从余额扣除 | [用量记录](https://cdn-api.onprs.online/usage) |
| 订阅套餐 | 购买套餐、套餐兑换码或运营分配 | 使用订阅有效期和额度窗口 | [我的订阅](https://cdn-api.onprs.online/subscriptions) |

同一账号可以同时拥有余额和一个或多个订阅，但具体请求使用哪一种由 API Key 的分组决定：

- 标准计费分组检查余额。
- 订阅分组检查该分组的有效订阅和额度；权益不可用时返回 `403`。

创建 Key 时选择对应的计费分组。

## 套餐页面中的字段

当前可售内容以[购买套餐](https://cdn-api.onprs.online/purchase)为准。常见字段包括：

- 套餐价格与划线原价。
- 续费折扣及当前是否符合续费条件。
- 有效期和对应分组。
- 库存和是否仍在售。
- 支持的模型范围。
- `5h / 7d / 30d` 美元额度。

价格、库存、促销和模型范围以购买页面的实时信息为准。

## 美元额度与实际付款

额度中的 USD 是统一的模型用量计价单位。请求成本通常由 Token、缓存、图片或按次价格计算，再应用分组、账号或时段倍率。

套餐标注的 `$10` 表示 `$10` 计价用量额度；订单支付金额和可退款金额以订单信息为准。

最终以[模型价格](https://cdn-api.onprs.online/model-pricing)、订单和用量记录为准。

## 多个权益同时存在

同一分组的不同套餐可以形成独立订阅。服务会选择当前仍有效且未耗尽的可用订阅；较早的套餐耗尽时，后续可用套餐仍可能接管请求。相同套餐再次购买通常续期同一条套餐权益。
