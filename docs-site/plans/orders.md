# 订单、支付与兑换码

## 订单状态

| 状态 | 含义 | 用户操作 |
| --- | --- | --- |
| 待支付 | 已创建但尚未确认付款 | 在有效期内完成付款，或取消订单 |
| 已支付 / 处理中 | 支付已确认，正在发放余额或订阅 | 保持当前订单并等待处理 |
| 已完成 | 权益已成功发放 | 到余额、订阅和用量页面核对 |
| 已失败 | 权益发放遇到错误 | 保留订单号并联系支持处理重试 |
| 已取消 / 已过期 | 订单未在有效期完成 | 创建新订单并使用新付款码 |
| 退款处理中 / 已退款 | 正在等待支付渠道或已经完成退款 | 按当前状态等待处理 |

支付结果以[我的订单](https://cdn-api.onprs.online/orders)状态为准，支付后刷新页面查看。

## 支付确认

- 每次购买使用一张订单付款页面。
- 订单显示“已支付”或“处理中”时，保持当前订单并等待权益发放。
- 收到扣款通知但订单仍待支付时，记录支付时间和渠道交易号，等待短暂同步后联系支持。
- 支付凭证提交给支持前，请遮盖账号和无关交易。

## 余额冻结

普通套餐购买与余额充值按订单状态处理。批量图片任务会在提交时冻结预计费用：成功项按实际规则结算，未使用部分在完成或取消后释放。冻结金额会单独显示；任务结束后仍未释放时，请提交批次 ID 和请求时间。

## 退款

退款能力取决于订单类型、支付实例、权益是否已消耗和当前运营政策。控制台为符合条件的已完成余额订单显示用户退款入口；订阅、部分退款和异常订单由支持人员处理。

退款状态包括“申请、处理中、渠道待确认、成功和失败”。提交一次申请后，按订单状态等待权益扣减和支付渠道确认。

## 兑换码类型

- 余额兑换码：增加或扣减余额。
- 并发兑换码：调整账号并发权益。
- 套餐兑换码：按分组和有效期发放订阅。
- 邀请码：在注册流程中使用。

套餐型兑换码分为两类：

- 按套餐生成的新式兑换码：绑定套餐身份并保存三档额度快照；同套餐兑换会续期该套餐。
- 旧式按分组兑换码：没有套餐身份，续期分组级 legacy 权益，并保留已有滚动额度快照。

兑换码一次使用，并受状态和到期时间限制。请在[兑换码页面](https://cdn-api.onprs.online/redeem)核对状态，需要时联系支持。
