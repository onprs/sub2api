# 购买、续费与权益快照

## 新购

创建套餐订单时，系统会把当时的以下信息记录到订单：

- 套餐身份、分组和有效期。
- 原套餐价格与本单实际价格。
- 本单适用的续费折扣。
- `5h / 7d / 30d` 额度。

支付完成后，系统按订单快照发放权益。已创建订单继续使用创建时固定的信息。

## 续费

续费折扣适用于“当前仍有效的同一个套餐”。同分组的其他套餐和已过期套餐按新购规则计算。

有效同套餐续费时：

- 继续使用同一条套餐订阅记录。
- 天数从原到期时间向后累加。
- 新订单的额度快照成为当前限额。
- 当前滚动窗口和已用额度保留，不因续费自动清零。

不同套餐即使属于同一分组，也可以形成独立权益。系统会从仍可用的权益中选择。

## 权益快照范围

快照固定订单或套餐兑换码中的价格、折扣和额度。具体模型仍会随上游、渠道维护、合规要求和平台能力调整。

同一套餐再次续费会创建新交易，并采用新订单创建时的价格、折扣和额度快照。

## 到期与重新激活

- 到期后，订阅分组暂停使用。
- 已过期同套餐再次购买时，从当前时间计算新有效期。
- 重新激活会清除旧滚动窗口的用量周期。
- 页面状态异步更新，刷新“我的订阅”和用量页面获取最新状态。

## 撤销与恢复

运营处理退款、风控或异常权益时，会根据处理结果撤销、暂停或恢复订阅。恢复后的状态由当前到期时间决定。

快照和权益状态由系统管理。如状态与订单不一致，按[联系支持](/account/support)提供订单号和时间。
