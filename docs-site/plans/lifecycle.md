# 购买、续费与权益快照

## 新购

创建套餐订单时，系统会把当时的以下信息记录到订单：

- 套餐身份、分组和有效期。
- 原套餐价格与本单实际价格。
- 本单适用的续费折扣。
- `5h / 7d / 30d` 额度。

支付完成后，系统按订单快照发放权益。创建订单之后管理员修改套餐，不会追溯改变这张订单已经固定的信息。

## 续费

续费折扣只在用户购买“当前仍有效的同一个套餐”时适用。仅同分组但不同套餐、或已经过期的套餐，不自动获得同套餐续费折扣。

有效同套餐续费时：

- 继续使用同一条套餐订阅记录。
- 天数从原到期时间向后累加。
- 新订单的额度快照成为当前限额。
- 当前滚动窗口和已用额度保留，不因续费自动清零。

不同套餐即使属于同一分组，也可以形成独立权益。系统会从仍可用的权益中选择。

## 权益快照不代表什么

快照保护的是订单或套餐兑换码已经固定的权益，不表示服务能力永久不变。具体模型仍可能因上游下线、渠道维护、合规要求或平台能力发生变化。

同一套餐后来再次续费属于一笔新交易，新订单会采用它创建时的价格、折扣和额度快照；这不是修改旧订单。

## 到期与重新激活

- 到期后，订阅分组请求会被拒绝。
- 已过期同套餐再次购买时，从当前时间计算新有效期。
- 重新激活会清除旧滚动窗口的用量周期。
- 页面状态更新可能稍有延迟，刷新“我的订阅”和用量页面确认。

## 撤销与恢复

运营处理退款、风控或异常权益时，订阅可能被撤销、暂停或恢复。恢复会根据当前到期时间决定显示为有效还是过期；不会绕过已过期的有效期。

用户不能自行修改快照或恢复被撤销权益。如状态与订单不一致，按[联系支持](/account/support)提供订单号和时间。
