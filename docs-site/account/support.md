# 联系支持

当前公开支持邮箱：[`839097298@qq.com`](mailto:839097298@qq.com)。

## API 或客户端问题

请提供：

- 发生时间、时区和是否可稳定复现。
- 客户端名称、版本和操作系统。
- Base URL、协议路径、模型名和是否流式。
- HTTP 状态码、完整错误码和错误正文。
- `x-request-id` 与 `x-client-request-id`（如有）。
- 删除敏感字段后的最小请求。
- 已完成的自查步骤。

## 套餐和额度问题

请提供账号邮箱、Key 名称或控制台 Key ID、分组、套餐名、窗口开始/重置时间、已用/剩余额度和一个失败请求 ID。

## 支付和订单问题

请提供系统订单号、支付时间、金额、方式、渠道交易号和当前页面状态。支付凭证需遮盖完整账号、银行卡号和无关交易。

## 敏感信息

以下信息请保留在本地：

- 完整 API Key。
- 登录密码、验证码或恢复码。
- Cookie、JWT 或浏览器存储。
- 上游账号凭据。
- 支付密码、银行卡完整信息。
- 与问题无关的用户数据、提示词或文件。

需要复现时，可新建低额度临时 Key，并在问题处理后立即撤销。
