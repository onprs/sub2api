# 注册与账号安全

## 注册和登录

1. 打开[控制台](https://cdn-api.onprs.online/)。
2. 使用页面当前提供的邮箱或第三方登录方式注册。
3. 如页面要求邮箱验证、邀请码、验证码或同意条款，按页面提示完成。
4. 登录后打开[个人中心](https://cdn-api.onprs.online/profile)，核对账号邮箱和绑定信息。

## 登录凭据与 API Key 的区别

| 凭据 | 用途 | 推荐管理方式 |
| --- | --- | --- |
| 登录密码、验证码、登录会话 | 访问控制台 | 密码管理器和两步验证 |
| API Key | 调用模型 API | 系统凭据库、环境变量或受限文件 |
| 上游厂商凭据 | 由服务运营方管理 | 无需配置到用户设备 |

普通 API 调用仅使用控制台创建的 API Key。浏览器登录 Token 用于控制台会话。

## 建议的安全设置

- 使用密码管理器生成并保存唯一强密码。
- 若个人中心提供双因素认证，优先启用并妥善保存恢复信息。
- 每台设备、每个应用和每个环境使用不同 API Key。
- 定期检查[用量记录](https://cdn-api.onprs.online/usage)和 Key 的最后使用时间。
- 离职、设备丢失、配置外泄或出现异常用量时，立即禁用或撤销相关 Key。
