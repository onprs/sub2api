# 支付与订单排查

## 已扣款但订单待支付

1. 不要再次支付同一订单。
2. 打开[我的订单](https://cdn.api.onprs.top/orders)刷新。
3. 等待支付渠道回调和页面轮询完成。
4. 记录订单号、支付时间、支付方式和渠道交易号。
5. 状态长时间不变时联系支持。

页面关闭、扫码完成或银行通知都不能单独证明系统已收到可信支付回调。

## 已支付但权益未到账

订单可能处于“已支付、处理中或失败”。余额或订阅只有在权益发放完成后才可使用。

- 对余额充值，检查当前余额和兑换记录。
- 对套餐，检查“我的订阅”中相同套餐和到期时间。
- 不要创建第二张订单来覆盖问题。
- 提供订单号和页面失败原因，支持可按幂等流程重试发放。

## 重复支付

保留两笔渠道交易号、金额和时间，不要自行发起更多订单。退款或补发取决于两张订单的系统状态和权益是否已发放。

## 订单过期后收到扣款

过期订单在有限宽限范围内可能被支付回调恢复；超过范围则需要人工核对。不要假设页面显示“过期”就可以忽略实际扣款。

## 退款等待

退款要经过权益扣减和支付渠道确认，状态可能是申请、处理中、渠道待确认、成功或失败。等待期间不要重复提交。

控制台没有退款按钮时，可能是订单类型或支付实例不允许用户自助退款，不代表自动满足退款条件。通过 `839097298@qq.com` 提交订单号、原因和必要脱敏凭证。

## 支持材料

- 账号邮箱。
- 系统订单号。
- 支付时间、金额和方式。
- 渠道交易号或脱敏凭证。
- 当前订单状态和失败文案。
- 余额或订阅页面的异常表现。

不要发送支付密码、验证码、银行卡完整号码、完整 API Key 或登录 Cookie。
