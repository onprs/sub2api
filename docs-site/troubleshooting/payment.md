# 支付与订单排查

## 已扣款但订单待支付

1. 保持当前订单，不再发起付款。
2. 打开[我的订单](https://cdn-api.onprs.online/orders)刷新。
3. 等待支付渠道回调和页面轮询完成。
4. 记录订单号、支付时间、支付方式和渠道交易号。
5. 状态长时间不变时联系支持。

支付结果以系统订单状态和可信支付回调为准。

## 已支付但权益未到账

在订单详情确认“已支付、处理中或失败”状态。余额或订阅在权益发放完成后可用。

- 对余额充值，检查当前余额和兑换记录。
- 对套餐，检查“我的订阅”中相同套餐和到期时间。
- 保留当前订单。
- 提供订单号和页面失败原因，支持可按幂等流程重试发放。

## 重复支付

保留两笔渠道交易号、金额和时间，暂停后续付款。退款或补发将根据两张订单的系统状态和权益发放情况处理。

## 订单过期后收到扣款

宽限范围内收到支付回调时，系统会恢复过期订单；超过宽限范围后转为人工核对。发生实际扣款时，请保留交易号并联系支持。

## 退款等待

退款要经过权益扣减和支付渠道确认，状态包括申请、处理中、渠道待确认、成功和失败。提交一次申请后按状态等待。

控制台显示退款入口时可自助提交；其他订单通过 `839097298@qq.com` 提交订单号、原因和必要脱敏凭证。是否符合退款条件以订单类型、支付实例、权益使用情况和当前政策为准。

## 支持材料

- 账号邮箱。
- 系统订单号。
- 支付时间、金额和方式。
- 渠道交易号或脱敏凭证。
- 当前订单状态和失败文案。
- 余额或订阅页面的异常表现。

支付密码、验证码、银行卡完整号码、完整 API Key 和登录 Cookie 请保留在本地。
