# 问题解答

## Base URL 应该填什么？

OpenAI 和 Anthropic 客户端填写 `https://cdn-api.onprs.online/v1`。Gemini CLI 的 `GOOGLE_GEMINI_BASE_URL` 填写 `https://cdn-api.onprs.online`，由客户端追加 Google 路径。

## API Key 和登录密码一样吗？

API Key 用于模型 API；登录密码、Cookie 和 JWT 用于控制台。请按各自用途配置。

## 必须设置环境变量吗？

环境变量是可选配置方式。也可以使用控制台“使用 Key”、客户端配置文件、凭据存储或客户端自带的 Key 设置。

## 为什么 `/v1/models` 成功，生成仍失败？

模型列表用于模型发现。生成请求还会校验余额、订阅额度、上游容量、协议字段和模型能力。

## 模型名从哪里复制？

使用当前 Key 请求 `GET /v1/models`；Google GenAI 客户端请求 `GET /v1beta/models`。从实际返回结果中复制模型名。

## 同一个模型能用四种协议吗？

服务支持四类入站协议和跨协议转换。具体模型、分组和能力以当前 Key 的模型列表及协议矩阵为准。

## 余额和套餐会同时扣吗？

单个请求按 Key 分组对应的计费方式处理：标准分组使用余额，订阅分组使用订阅权益。

## 5h / 7d / 30d 是三选一吗？

套餐配置的窗口会同时检查，请求需要各窗口均有剩余额度。

## “无限额”是什么意思？

表示该窗口没有配置限制，不代表没有套餐有效期、其他窗口、Key 额度、并发、RPM 或上游限流。

## 续费会清空已用额度吗？

有效套餐续费会延长有效期并应用新订单额度快照，但保留当前窗口和已用量。已过期后重新激活会开启新的滚动周期。

## 为什么续费没有折扣？

只有仍有效的同一个套餐符合其续费折扣。不同套餐、仅同分组或已经过期的套餐不自动符合。

## 套餐后来修改会影响我的订单吗？

订单创建时会固定价格、折扣和滚动额度快照，之后修改套餐不会追溯改变该订单。下一次新购或续费使用新订单自己的快照。

## 可以同时买同分组多个套餐吗？

不同套餐可形成独立权益。服务会选择当前未耗尽且有效的订阅；有效期内再次购买同一套餐会续期该权益。

## 为什么流式请求更容易触发并发？

流在连接结束前持续占用并发。多个 agent、自动重试和长时间工具调用会叠加。

## 429 都是上游限流吗？

429 的来源包括 Key 额度、订阅窗口、RPM、并发和上游限流。先查看机器错误码和重试时间。

## 是否支持 OpenCode Go？

支持。OpenCode Go 按独立平台配置，可通过 Chat Completions、Messages 和标准 HTTP Responses 执行。

## 联系支持要发 Key 吗？

提供 Key 名称或 ID、请求 ID、时间、客户端版本和脱敏请求即可，完整 Key 请保留在本地。
